# 株式会社原マシナリー 会社紹介動画 ｜ 絵コンテ・制作指示書

**コンセプト：大きな機械に、確かな技術を。**

本書は、同ディレクトリの `index.html`（ブラウザで再生できるプリビズ映像＝動く絵コンテ）に対応する
制作指示書です。尺・カット割り・テロップ・ナレーションのタイミングはプリビズと完全に一致しており、
実写素材が揃い次第、同じタイムラインのまま差し替えられる構成になっています。

| 項目 | 内容 |
| --- | --- |
| 総尺 | 48秒（本編45.6秒＋エンドカード余韻） |
| 画角 | 16:9 / 1920×1080 / 30fps |
| トーン | 重厚・シネマティック。町工場紹介ではなく、日本の製造企業のブランドムービー |
| 基調色 | 黒・ダークグレー・金属色・白。アクセントにアンバー（火花と同系） |
| 音 | 重厚シネマティック系BGM ＋ 工場SE（BGMとナレーションを邪魔しない音量） |

### 00:15 – 00:28 ｜ 大物精密機械加工（13秒）★最大の見せ場

4つのビートで構成する。**この13秒に最も予算と手間をかけること。**

| 秒 | 画 | 狙い |
| --- | --- | --- |
| 15.0–18.2 | 天井クレーンが巨大ワークを吊り下ろし、門型機のテーブルに着座。傍らに人物を立たせ、大きさを対比。着座で粉塵と微振動 | **「こんなに大きなものを扱えるのか」** |

| 22.4–25.2 | 刃先の超接写。切粉がカールし、火花が大きく散る。被削面のツールマークが見える | **大きさと繊細さのギャップ** |
| 25.2–28.0 | 加工を終えた大型部品。表面をハイライトが舐めるように走る。公差表示を重ねる | **精度** |

| | |
| --- | --- |

## 3. 撮影素材リスト（実写差し替え用）

優先度A＝この動画に必須。B＝あると質が上がる。

| 優先 | 素材 | 使用箇所 |
| --- | --- | --- |
| A | 大型工作機械（門型・五面加工機など）の全景 | 00:00 / 00:15 |
| A | 巨大ワークの搬送・段取り（クレーン、玉掛け） | 00:15–00:18 |
| A | 切削の寄り（工具・切粉・クーラント） | 00:18–00:25 |
| A | 加工完了した大型部品 | 00:25–00:28 |
| A | 工場外観 | 00:41–00:44 |
| A | 会社ロゴ（ベクターデータ） | 00:44–00:48 |
| B | CAD画面・設計作業 | 00:05–00:09 |
| B | 専用機の組立工程・完成した専用機 | 00:09–00:15 |
| B | 各産業向け加工品（自動車・航空宇宙・工作機械） | 00:28–00:36 |
| B | シリコン／石英／セラミック／サファイアの加工品 | 00:32–00:38 |
| B | 技術者の作業（操作盤・測定・打ち合わせ） | 00:38–00:41 |

**撮影の要点**

- 大物カットは必ず**人と並べて撮る**。スケール感は対比でしか伝わらない。
- 切削は望遠マクロで。火花が背景の暗部に抜けるようライティングを組む。
- 工場のリアルな質感を残す。過度にクリーンにしない。
- コントラストはやや強め。金属のハイライトを飛ばしきらない。

## 4. テロップ規定

- **一画面一メッセージ。** 長文は出さない。
- 書体：Noto Sans JP（Bold / Black）。字間は広め（0.08–0.14em）。
- 位置：左下を基準に、セーフエリア内。ナレーション字幕とは重ねない。
- 出：ワイプ状に0.45秒で立ち上げ、下から16px上げる。消：0.35–0.55秒でフェード。
- 見出しの下にアンバーの罫線を1本、テキスト幅まで伸ばす。

| 使用可 | 使用不可 |
| --- | --- |
| `1948年創業` `専用機 設計・製作` `大物精密機械加工` `大型ワーク × 高精度加工` `多品種・少量にも対応` `確かな技術力` `100年企業へ` | 「当社ではお客様のニーズに合わせてさまざまな製品を製造しています。」のような説明文 |

## 5. 音の設計

**BGM**：重厚なシネマティック／テクノロジー系。静かに始まり、大型機械が映るところから徐々に盛り上げ、
大物加工（00:15–00:28）でピーク。最後は余韻を残してロゴへ。

| 区間 | 密度 |
| --- | --- |
| 00:00–00:05 | ドローンのみ |
| 00:05–00:15 | 拍が入る（1.5秒周期） |
| 00:12.4–00:15 | ライザー |
| 00:15–00:28 | ピーク（0.75秒周期＋和音） |
| 00:28–00:38 | 維持、和音を1段上げる |
| 00:38–00:44 | 解決、減速 |
| 00:44–00:48 | 余韻・減衰 |

**SE**：工作機械の起動音／金属を削る音／工具の移動音／エアー音／駆動音／クレーン音／金属音。
いずれもBGMとナレーションを邪魔しない音量に抑える。ナレーションのある区間は-6dB程度ダッキング。

**ラウドネス**：-14 LUFS（配信基準）／トゥルーピーク -1.0dBTP 以下。

## 6. 実素材・AI生成素材の扱い（厳守）

本プリビズは全編CGによるイメージ映像として制作している。実制作でも以下を守ること。

1. 実在しない製品を「原マシナリーの製品」として断定しない。
2. 存在しない社員や工場設備を、実写の会社紹介として誤認させない。
3. 実際の設備写真・工場写真・製品写真が提供された場合は、**それらを最優先で使用する**。
4. 会社ロゴは提供された正式なロゴデータのみを使用する。
5. 機械の形状や加工シーンを、実際の事業内容から大きく逸脱させない。
6. AIで補完した映像は、あくまで「イメージ映像」として扱い、画面に明示する。

プリビズ側では、人物はすべて個人を特定しない抽象シルエットとし、
画面右上に「映像はすべてCGによるイメージです」を常時表示している。
実写差し替え後、この表示の要否を再判断すること。

## 8. プリビズの使い方

`index.html` をブラウザで開くと、48秒の映像がそのまま再生できる。

- 再生／一時停止、シーク、チャプタージャンプ（6シーン）が可能
- 音声はブラウザ内で合成（BGM・SEともにプログラム生成）。ON/OFF切り替え可
- ナレーションは字幕として表示。ON/OFF切り替え可
- ページ下部にカット表・会社概要・キーワードを併載

尺やテロップ文言を変更する場合は、`index.html` 冒頭の `SC`（シーン区切り）、
`NARR`（ナレーションのイン点・アウト点）、`CUTS`（カット表）を書き換えれば、
映像・字幕・カット表がすべて追従する。
