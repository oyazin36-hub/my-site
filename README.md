## hara-machinery — 株式会社原マシナリー 会社紹介動画

「大きな機械に、確かな技術を。」をコンセプトにした48秒の会社紹介動画。

| ファイル | 内容 |
| --- | --- |
| [`hara-machinery/index.html`](hara-machinery/index.html) | 本編。ブラウザで開くとそのまま再生できる48秒の映像。映像はCanvasで、BGM・SEはWeb Audioでプログラム生成しており、外部の動画・音声ファイルを持たない |
| [`hara-machinery/STORYBOARD.md`](hara-machinery/STORYBOARD.md) | 絵コンテ・制作指示書。実写制作に移行する際の台本 |

映像は全編CGによるイメージ映像です。実在しない製品・設備・社員を実写として提示しないという方針のもと、
機械と加工シーンは抽象化した形状で描画し、人物は個人を特定しないシルエットとしています。
実際の設備・製品写真や正式なロゴデータが提供された場合は、そちらを優先して差し替えてください。
