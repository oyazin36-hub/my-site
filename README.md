# 相見積もり比較アプリ

複数社の見積書PDFから **品番** と **単価** を自動で読み取り、
**単価 × 倍率（100円単位で切り上げ）** で各社を横並び比較するWebアプリです。

人が入力するのは **社名** と **倍率** だけ。AIビジョンは使わず、
OCR（Tesseract）＋ 画像の前処理（傾き補正・罫線除去・くっきり化）で読み取ります。

## 主な機能
- PDF（スキャン画像でもOK）をアップロード → 品番・単価を自動抽出
- 品番（`xxx-Mxxx`）で各社を自動マッチング
- 社名・倍率を入力 → 単価×倍率を **100円単位で切り上げ** して比較
- 各品番の **最安値を緑でハイライト**
- 読取りの **信頼度を表示**（◎=複数回の読みが一致 / ○=2回一致 / △=要確認）
- △・要確認のセルは **単価をクリックして手修正**（原本の切り出し画像をホバー表示）
- **A4で印刷**（「🖨 A4で印刷」ボタン → 用紙A4で印刷）

## 読取りの前提
- 単価は **10円きざみ**（末尾0）。1円単位の端数は読み間違いとして除外。
- 金額列（=単価×数量）は使わない。回答に使うのは単価のみ。

## セットアップ
```bash
# 1. Tesseract本体（日本語）をインストール
#    Ubuntu/Debian:
sudo apt-get install -y tesseract-ocr tesseract-ocr-jpn
#    macOS:
#    brew install tesseract tesseract-lang

# 2. Pythonライブラリ
pip install -r requirements.txt

# 3. 起動
python app.py
# → ブラウザで http://127.0.0.1:5000 を開く
```

## 使い方
1. 各社の見積書PDFを選んで「読み取る」
2. 「社名」と「倍率」を入力（倍率を変えると比較表が即再計算）
3. △・要確認のセルがあれば、単価をクリックして原本と照合・修正
4. 「🖨 A4で印刷」で印刷

## 構成
```
app.py                  Flask本体（アップロード / 読取りAPI）
ocr/pipeline.py         OCRパイプライン（画像化→前処理→品番・単価抽出）
templates/index.html    画面（アップロード / 入力 / 比較表 / 印刷）
static/style.css        スタイル（画面表示 + A4印刷用）
```

## 注意
- 金額を扱うため、**△・要確認のセルは印刷前に原本（PDF）と照合**してください。
  ◎は複数回の読みが一致した高信頼の値ですが、自動読取りである以上、最終確認を推奨します。
