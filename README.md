# 社内帳票管理アプリ

購入依頼などの社内帳票を、スマホ・PCで入力し、承認・集計まで管理するWebアプリです。

## 主な機能

- **帳票入力**(スマホ・PC両対応):明細行の追加/削除、単価の「不明」ボタン、先行発注済トグル
- **ダッシュボード**:月別/従業員別/項目別の切り替え、進捗バー(総務→課長→副社長→社長)
- **承認・差戻し**:各承認者が画面上で承認、理由を添えて差戻し
- **品名の入力候補**:過去に入力した品名を予測表示
- **下書きの自動保存**:入力途中で画面を閉じても内容が残る
- **親切な必須チェック**:未入力欄をその場で赤く表示
- **承認待ちのメール通知**(任意設定)
- **アプリ化(PWA)**:スマホのホーム画面に追加して、アプリのように起動

## すぐ試す(デモ)

`index.html` をブラウザで開くだけで、サンプルデータで全画面を操作できます
(Google連携が未設定のときは自動でデモ動作になります)。

## 本番で使う(Google スプレッドシート連携)

1. Google スプレッドシートを新規作成
2. 「拡張機能」→「Apps Script」を開き、`gas/コード.js` の内容を貼り付けて保存
3. 「デプロイ」→「新しいデプロイ」→「ウェブアプリ」
   - 次のユーザーとして実行:**自分**
   - アクセスできるユーザー:**全員**
4. 発行された URL を `js/config.js` の `GAS_URL` に設定
5. (任意)承認者へのメール通知は `gas/コード.js` の `EMAIL_MAP` に宛先を設定

## スマホのホーム画面に追加(アプリ化)

HTTPS で公開(例:GitHub Pages)したうえで、スマホのブラウザで開き
「ホーム画面に追加」を選ぶと、アイコンから起動できます。

## 帳票を追加するには

1. `js/forms/purchase.js` をコピーして新しい帳票ファイルを作る
2. `render` / `collect` / `toRow` などを新しい帳票に合わせて編集
3. 新しい帳票ファイルの最後で `REGISTERED_FORMS` に追加
4. `index.html` に `<script src="js/forms/新しい帳票.js"></script>` を追加

## ファイル構成

```
index.html            アプリ本体
css/style.css         デザイン(スマホ・PC対応)
js/config.js          設定(GAS URL・従業員リスト・承認フロー)
js/app.js             画面遷移・ダッシュボード・承認・下書き等のロジック
js/forms/purchase.js  購入依頼表の帳票定義
gas/コード.js          Google スプレッドシート連携(GASに貼る)
manifest.json, sw.js  PWA(アプリ化)用
icons/                アプリアイコン
```
