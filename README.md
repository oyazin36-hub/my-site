# 選出ナビ for Pokémon Champions

ポケモンチャンピオンズの対戦前に使う、非公式のプレイヤーサポートアプリです。
スマホのブラウザだけで動きます(アプリストア不要・無料・通信データはどこにも送信されません)。

## できること

| 機能 | 説明 |
|---|---|
| 相性マトリクス | 自分6匹 × 相手6匹の有利不利を色で表示(緑=有利/黄=五分/赤=不利) |
| おすすめ選出 | どの3匹を出すべきかを理由つきで提案 |
| 対面詳細 | マスをタップすると「効く技」「どちらが先に動くか」「警戒すべき技」を表示 |
| PT診断 | チームの長所・短所・「出てきたら不利なポケモン」を自動診断 |
| スクショ読み取り | 対戦画面のスクショから相手6匹を自動入力(使うほど賢くなる自己学習式) |

## 公開のしかた(GitHub Pages・無料)

1. GitHub でこのリポジトリを開く
2. **Settings** → 左メニューの **Pages** を開く
3. 「Build and deployment」の Source を **Deploy from a branch** にする
4. Branch でこのブランチ(または main にマージ後は main)と **/ (root)** を選んで **Save**
5. 1〜2分待つと `https://<ユーザー名>.github.io/my-site/` でアプリが開けるようになる

## スマホのホーム画面に追加する(アプリ化)

- **iPhone (Safari)**: 上のURLを開く → 共有ボタン(□に↑)→「ホーム画面に追加」
- **Android (Chrome)**: 上のURLを開く → 右上の「︙」→「ホーム画面に追加」(または「アプリをインストール」)

一度開けばオフラインでも動きます。

## 使い方

1. **マイPT** タブで自分のポケモンを最大6匹タップして登録(1回だけでOK・自動保存)
2. 対戦が始まったら **相手入力** タブで相手の6匹をタップ(6匹そろうと自動で結果へ)
3. **結果** の表の色を見て選出を決める。迷ったらマスをタップして詳細を確認
4. **PT診断** タブでチームの弱点チェック

### スクショ読み取りの使い方

1. 対戦のチーム確認画面でスクショを撮る
2. 「相手入力」→「📷 スクショを選ぶ」で読み込む
3. **初回だけ**: 画像の中の相手ポケモン6匹を左から順にタップ → 名前を選んで教える
4. 2回目からは同じ位置を自動で読み取り、教えたことのあるポケモンは自動で認識します
